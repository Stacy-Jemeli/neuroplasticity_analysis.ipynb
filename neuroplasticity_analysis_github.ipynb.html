What to do on GitHub

Your repository should look like this:

your-repository/
├── README.md
├── requirements.txt
├── .gitignore
├── DATA_AVAILABILITY.md
├── ANALYSIS_PLAN.md
├── MODEL_CARD.md
├── CITATION.cff
└── neuroplasticity_analysis.ipynb

The commands shown in the README are instructions only. GitHub displays them but does not execute them.

If you are using Kaggle

  1. Sign in to Kaggle.

  2. Go to Code.

  3. Select New Notebook.

  4. Select File → Import Notebook.

  5. Upload or select:

neuroplasticity_analysis.ipynb

  1. Add your data using Add Input.

  2. Keep the Kaggle notebook and dataset Private.

  3. Run the notebook cells from top to bottom.

The first Kaggle cell can list the available input files:

Python
from pathlib import Path

for file_path in Path("/kaggle/input").rglob("*"):
    if file_path.is_file():
        print(file_path)

After running it, Kaggle will display your dataset’s path, for example:

/kaggle/input/cerebral-palsy-private-data/analysis_dataset.csv

Use that exact path:

Python
from pathlib import Path
import pandas as pd

DATA_FILE = Path(
    "/kaggle/input/cerebral-palsy-private-data/analysis_dataset.csv"
)

if not DATA_FILE.exists():
    raise FileNotFoundError(f"Dataset not found: {DATA_FILE}")

df = pd.read_csv(DATA_FILE)

print("Dataset loaded successfully")
print("Rows:", df.shape[0])
print("Columns:", df.shape[1])

If you want to run it through GitHub

GitHub normally displays notebooks but does not run them. You can connect the notebook to Google Colab.

Add this link near the top of README.md:

Markdown
## Run the analysis

The notebook can be opened in Google Colab:

[Open the notebook in Google Colab](https://colab.research.google.com/github/YOUR_USERNAME/YOUR_REPOSITORY/blob/main/neuroplasticity_analysis.ipynb)

Replace:

YOUR_USERNAME

with your GitHub username, and replace:

YOUR_REPOSITORY

with the repository name.

For example:

Markdown
[Open the notebook in Google Colab](https://colab.research.google.com/github/stacyngetich/cerebral-palsy-neuroplasticity-prediction/blob/main/neuroplasticity_analysis.ipynb)

If the repository is private, Colab may ask you to authorize access to GitHub.

README explains the project

Notebook contains the code
